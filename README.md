# NA GOLCI — WOW version

Отдельная локальная версия сайта тату-студии. Исходный проект находится в соседней папке `../site`.

## Запуск

Требуется Node.js 22.13+.

```bash
npm ci
npm run dev -- --port 4318
```

Открыть <http://localhost:4318/>. Локальная база создаётся при первом запросе. Данные и медиа редактируются через существующую админку `/admin`.

## Что внутри

- Публичная страница: крупная типографика, асимметричная галерея, блок мастера, запись, отзывы и контакты.
- Существующие тексты, фотографии, ссылки и контентная модель сохранены.
- Цвета: тёмные фоны по всей странице, тёплый светлый текст, фирменный красный.
- Настройки публикации исходного проекта в эту папку не скопированы.

Концепция и критерии проверки: [docs/wow-design.md](docs/wow-design.md).
