## Уточнения к плану

- При смене **самой композиции** 999→1000 px (мастер) и 1199→1200 px (процесс) высота закономерно меняется: последовательный блок становится колонками. На 1199/1200×900 это 1363→822 px. Убирать разницу искусственной пустотой не стали. Внутри одной композиции прежний скачок на 1500 px устранён. Это отклонение от буквального требования плана о любой разнице в 10 px; при непрерывном resize граница заметна.
- Длинный заголовок процесса на узком телефоне может быть 36 px вместо общего минимума 48 px: обе строки помещаются без изменения текста. Остальные h2 в общей шкале.
- Непрерывное колесо использует ограниченный `internalEngine()` Embla 8.5.2, поскольку публичный API работает по слайдам. При обновлении Embla нужен повторный тест этого обработчика.

## Оставшиеся ограничения

1. Физические swipe/pinch в Safari/iOS/Android не проверялись. Pointer-обработчик реализован, правила жеста покрыты unit-тестом. Нативный pinch и мультикасание надо проверить на устройстве до публикации.
2. Живое переключение OS reduced motion не выполнялось: доступная браузерная автоматизация не предоставляет такой эмуляции. CSS/JS условия проверены по коду, подавление инерции — unit-тестом; функциональная смена media query требует отдельного прогона.
3. Красный текст кнопок на черном оставлен по утвержденному стилю; соответствие WCAG AA всей страницы не заявляется.
4. Ноль/одна работа в lightbox и резервные контакты проверены по ветвлениям кода, без изменения реальных данных сайта.
5. Масштабирование браузера выявило сбой тестового таба: новый таб восстановил CSS viewport и снимки. Чистая матрица сделана при DPR=1. Полная 200%-zoom проверка ещё не выполнена.

Порядок работ сохранён. Для отдельного сравнения можно позже показать первые три кадра «пташки → чорно-червона змія → кольорова робота на передпліччі» (id 30/31/5), чтобы заявленный цвет был виден раньше. Это предложение, не реализованная перестановка.
