# Портрет на ширинах до 1000 px — 02.10.2026

Причина пустой полосы: `object-fit:contain` вписывал портрет по высоте, а `object-position:right top` оставлял незаполненное пространство слева. Боковая маска была отключена.

Фото теперь заполняет ширину через `cover`, с привязкой к верхнему краю. Высота фото и начало текста зависят от ширины окна; общий диапазон высоты 440–800 px. Боковое и вертикальное затухание объединяют фото с фоном. Избыточные отдельные переопределения высоты на 760/500 px убраны.

Визуально проверены 320×740, 390×844, 600×1000, 768×1100, 820×1180, 984×1300 и соседняя десктопная композиция 1000×900. Волосы и лицо видны, борода не пересекается с заголовком, чёрной полосы и резкого левого края нет. Горизонтальное переполнение не обнаружено при замерах 390–1000 px.

Скриншоты до/после находятся в `assets/`. `npm run build` завершился с кодом 0; `git diff --check` — без замечаний.
